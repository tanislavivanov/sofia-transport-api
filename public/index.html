Sofia Public Transport API v1.0.0

API Base URL

All endpoints are relative to your deployment. When running locally, the base URL is:

Current origin
https://your-server.example.com

Replace with your own domain when you deploy. There is no separate sandbox; use the same base URL for all requests.

Authentication

No API key required. All endpoints are public. Simply send a request to the base URL and path; no headers or query parameters are needed for authentication.

Example: GET /api/stops returns the full list of stops with no authentication.

About this API

Public JSON API for Sofia public transport (buses, trams, trolleys).

This API serves GTFS static (stops, routes, trips) and GTFS Realtime (trip updates, predicted arrivals) data from the Sofia Urban Mobility Centre. Data is fetched from gtfs.sofiatraffic.bg and cached: static data for about 30 days, realtime data for about 1 minute.

All responses are JSON. CORS is enabled for all origins. No API key or authentication is required. Stop lookups use the public stop code (e.g. 1708). When multiple GTFS stop IDs share the same code (e.g. bus and trolley at the same stop), the API merges them into a single stop and combines arrivals.
